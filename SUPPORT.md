# Support

TraceReplay is an early-stage open-source project.

## Where to ask for help

- **Usage questions:** use GitHub Discussions when enabled.
- **Bug reports:** open a GitHub Issue and include a minimal reproduction.
- **Feature ideas:** open an Issue describing the use case and desired behavior.
- **Security vulnerabilities:** do not use public Issues; follow [SECURITY.md](SECURITY.md).

## What to include

For technical questions, include:

- TraceReplay version or commit.
- Python version.
- Operating system.
- Relevant configuration with secrets removed.
- A minimal code example.
- Full error message or traceback, after removing private information.

## Before asking

Check the README, documentation, existing Issues, and Discussions for an answer.

Please do not upload API keys, access tokens, customer information, private prompts, or unredacted recordings.
